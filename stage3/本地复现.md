# 从 stage3 目录复现终点三

打开本目录，按 [README](README.md) 创建 Python 3.11 环境并安装。命令 `qlf-stage3 --version` 可查看已安装的版本。

**公开演示**从 `qlf-stage3 demo-data --out data/demo` 开始。**授权研究复现**使用 `data/study`。以下命令会从研究原图、掩膜和配准记录计算 QLF 特征，随后跑完灰度与 RGB 的全部三种子比较。

```powershell
qlf-stage3 endpoint --data data/study --out runs/my-endpoint
qlf-stage3 verify --run runs/my-endpoint --reference-study
```

总报告位于 `runs/my-endpoint/stability/report.md`，过程日志为 `runs/my-endpoint/stability/run.log`。每次完整运行使用新的输出目录。复现先前的灰度研究可调用 `qlf-stage3 run`。[分步重跑、离线权重和无标签推理](docs/reproducibility.md) · [历史实验](experiments/README.md)
