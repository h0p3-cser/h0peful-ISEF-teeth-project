# 目标 2：QLF 图像的颜色通道处理

把 QLF（定量光诱导荧光）牙片的 RGB 拆开、量化、加权，用来回答：
**这张图里绿色荧光和红色荧光各自在哪强、在哪弱，哪里出现了真正的"颜色偏移"。**

一个处理方式 = 一个脚本，每个文件头都写清了「对哪个颜色、做了什么、公式是什么」。
所有脚本产出的文件名同时说明了处理方法，例如 `S0_09_绿光加权_去光照_幂律p2_乘色度.png`。

## 一、快速开始

```bash
cd goal2-color-processing
pip install -r ../requirements.txt     # numpy pillow scipy matplotlib

# 单跑一个：只出那一个文件
python3 09_绿光加权_去光照_幂律_色度.py 你的图.jpg -o out/S0

# 全部跑完：按 01→15 顺序执行
python3 run_all.py 你的图.jpg -o out/S0

# 改参数（只影响 09 / 10 / 12）
python3 run_all.py 你的图.jpg -o out/x --power 3
```

每个脚本都能单独运行；不写 `-o` 就输出到输入图旁边。
脚本会把自身目录加进 `sys.path`，所以从任何目录调用都可以。

> ⚠️ `_common.py` 与 `_metrics.py` 是本目录的一部分，**必须和 0x 脚本放在一起**。
> 它们只放"和算法无关的杂活"（读图、存图、百分位归一、命名）与"统计内核"（14/15 共用），
> 真正的处理公式都在各自的 0x 脚本里。

依赖：

```
numpy
pillow
scipy
matplotlib
```

## 三、每张图对 RGB 做了什么

### 01–06：单通道分离

| 编号 | R | G | B | 说明 |
| --- | --- | --- | --- | --- |
| 01 | `0` | `G` | `0` | 纯绿图。人眼对绿的亮度感知不可靠，比强弱别用它 |
| 02 | `G` | `G` | `G` | 同一份数据转灰度。**做亮度比较用这张** |
| 04 | `R` | `0` | `0` | 纯红图 |
| 05 | `R` | `R` | `R` | 红通道灰度版 |

03 / 06 不碰原图，只统计 `hist[i] = #{像素 | 通道值 = i}`，
画成 512×220 画布（白底，柱色 绿 `(40,160,70)` / 红 `(220,60,60)`，底部黑轴）。

### 07 比值图

```
Rs = gaussian(R, σ=2),  Gs = gaussian(G, σ=2)      # 去 JPEG 块噪声
lr = log2( (Rs+1) / (Gs+1) )                       # +1 避免除 0
颜色 = coolwarm( clip((lr + 0.30) / 0.80, 0, 1) )
```

输出的 RGB **与原始 RGB 无关**，只是把 `lr` 这一个数涂成颜色：
蓝 = G 强，白 = 中性，红 = R 强。

### 08 红色过量

```
1) 全图最小二乘拟合   R = a·G + c
2) 残差               R′ = Rs − (a·Gs + c)
3) 对称色带           ±max(|p0.5|, |p99.5|) 映射到 coolwarm
```

红 = 比耦合律预测的更红（真颜色信号），白 = 符合规律，蓝 = 更绿。
`a`、`c` 逐图拟合，所以写进文件名：S0 = `(0.649G+19.2)`，S2 = `(0.856G+28.3)`。

### 09 / 10 荧光加权（09 用 G，10 用 R）

```
1) 去光照  F  = I / gaussian(I, σ=长边/12 ≈ 159px)
2) 归一    v  = (F − p0.5) / (p99.5 − p0.5)，截到 0~1
3) 幂律    v²                      p=2
4) 色度    × (0.5 + 0.5·w)
5) 压高端  out / p99.5
```

色度权重 `w`：

```
lr  = log2( gaussian(R,6) / gaussian(G,6) )
d   = | lr − median(lr) |                    以本图中位色偏为零点
d′  = √(d² + 0.02²) − 0.02                   软绝对值，避免画出追踪线
w0  = clip(d′ / 0.30, 0, 3)
w   = w0 / (1 + w0)                          平滑饱和
```

09 与 10 用**同一个 w**，所以两张的差异只来自 `F_G` 与 `F_R` 本身。
输出为三通道相等的灰度 PNG（R=G=B）。

### 11 原图彩色 × 色度权重

```
out(x,y) = (R,G,B)/255 × w(x,y)      三通道同乘，色调不变、只改亮度
```

中性（R≈G）的地方被压暗，偏色区留下。

### 12 / 13

纯排版，不改数据：12 把 1–9 的核心结果拼成九宫格
（色带：4/5 用黑→饱和色→白，6/9 用 coolwarm）；
13 画四个统计面板（原始直方图、log2 双峰 + Otsu、R–G 散点 + 耦合律、去光照后的起伏分布）。

### 14 / 15

不产图。测量项：`corr(R,G)`、去光照后的相对起伏、`R/G` 分位与 Otsu 分界、
红偏面积、高频纹理能量、耦合律 `a/c/R²`、红色过量分位。
14 排成文本，15 存 json。

## 四、两条图上的实测结论

| 指标 | S0 基线 | S2 脱矿 72h |
| --- | ---: | ---: |
| corr(R,G) | 0.920 | 0.991 |
| 耦合律 | 0.649G+19.2，R²=0.847 | 0.856G+28.3，R²=0.982 |
| R/G 中位 | 0.778 | 1.038 |
| 去光照后 G 起伏 | 13.4% | 26.5% |
| 红偏面积 | 29.6% | 37.4% |

要点：

1. **R 与 G 高度同步**（r≈0.92–0.99，`R = aG + c` 就能解释 85–98% 的 R），
   整幅图的明暗主要是打光，不是荧光本身。
2. **去掉光照后 G 的起伏比 R 大 18%**，绿通道信息更多，病灶检测优先看 G。
3. **R/G 随亮度单调变化**：G 在 32–95 区间 R/G≈1.30，160 以上≈1.01，
   所以直接拿 R/G 当指标会和"变暗"混淆；**红色过量（08）才是干净的颜色指标**。
4. **变褐时 G 掉得比 R 多**（G −61.7%，R −51.1%），褐变主要吃掉绿光。

⚠️ 这两张图的拍摄条件不同（B 通道均值 13.7 vs 1.7，构图也不同），
上表不能直接当"脱矿前 vs 脱矿后"的定量结论。跨图只能比"图内相对量"
（病变区 vs 正常区），纵向比较需要同角度、同曝光，最好放标准色卡做白平衡。
