# h0peful-ISEF-teeth-project

Research code for RGB and quantitative light-induced fluorescence (QLF) experiments on dental images.

| Project | Scope |
| --- | --- |
| [Stage 1 — RGB baseline](stage1/README.md) | Caries detection, enamel-caries staging, and cross-dataset evaluation on public RGB datasets |
| [Stage 3 — QLF and white-light stage classification](stage3/README.md) | [v1.2.0](stage3/CHANGELOG.md) · Signed reference-255 QLF measurements, four-feature export at 30%, and paired original RGB/grayscale three-model evaluation with leave-one-tooth-out validation |

Each stage has its own dependencies, input description and reproduction commands. Original experimental images and full generated datasets are not distributed with this repository.
